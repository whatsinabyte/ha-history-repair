Welcome to History Repair

Three short steps before you correct anything.

1

Back up Home Assistant

This app writes directly to your recorder database. Every change is recorded and reversible from inside the app, but a full backup is your safety net if something goes wrong at a level this tool cannot undo. Create one from Settings → System → Backups before continuing.

It also has read-write access to your entire Home Assistant configuration directory, not only its own. This is required to reach home-assistant_v2.db when using the default SQLite recorder — SQLite is a single file, and there is no way to grant access to just that one file. If you use an external MariaDB or PostgreSQL instead, this app never uses that wider access, but Supervisor still requires it be granted for every mode to work.

2

Check the database connection

Confirms the app can reach your recorder database, that its schema is one this app understands, and that it may write.

Not tested yet.
3

Find the app later

History Repair appears in your Home Assistant sidebar, so there is nothing to add to a dashboard. If you would rather embed it in one, add a webpage card with this configuration: 

type: iframe
url: {{ url_for('index') }}
title: History Repair
aspect_ratio: 100%

Confirm your backup and test the connection first.
